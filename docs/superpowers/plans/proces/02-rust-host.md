# Rust native host

Status: complete for the initial native host gate. Native service parity is tracked separately.

Implemented a Tauri 2.12.5 host with isolated native preview identity, application data and Go configuration, trusted renderer IPC, native settings persistence, project folder selection, scoped file browsing and revision checked editing. The existing Go engine is loaded through its versioned C ABI in the application process. Engine initialization runs on a worker and publishes runtime status; requests run on blocking workers; events are forwarded incrementally through `prime:event`. The library remains loaded for the process lifetime and receives explicit shutdown. Attachments support native selection, base64 images, bounded retention, send resolution and release. Browser and Git service modules are connected. Editor close confirms unsaved changes.

Validation: Windows `cargo check` passed with the connected Go engine, browser, Git, SSH and launch services. The native window loads the existing React design, and actual WebView IPC creates a workspace, a session and an empty history page. The combined host tests passed before the additional SSH service group, including native DLL workspace/session creation, filesystem traversal and stale revision protection, settings persistence, attachment expiry and secret redaction. Debug builds accept an absolute `PRIME_NATIVE_TEST_DATA` override before constructing the application, covering Tauri config/data/cache/log paths, default WebView profiles, native settings and the Go engine. Missing capability methods return explicit errors. Production Electron packaging and data remain unchanged.
