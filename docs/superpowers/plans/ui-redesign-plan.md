# План переработки UI

## Текущая проблема
UI выглядит "косо" и неэстетично - простые блоки без визуальной структуры.

## Целевой результат
Современный TUI UI в стиле OpenCode с:
- Четкой визуальной иерархией
- Цветовой схемой (темная тема с акцентами)
- Компактным отображением сообщений
- Интуитивной навигацией

## Этапы реализации

### 1. Создание темы (theme.rs)
- Определить цветовую палитру
- Создать стили для разных элементов

### 2. Переработка App модели (app.rs)
- Добавить Messages view вместо простого списка
- Улучшить header с красивой надписью
- Оптимизировать input bar

### 3. Создание компонентов сообщений
- Assistant message - с акцентными элементами
- User message - четкое выделение
- Tool call output - таблицы/блоки

### 4. Обновление widgets.rs
- Добавить render_message для отображения сообщений
- Улучшить ToolCallWidget

### 5. Обновление TUI цикла
- Интегрировать новые компоненты
- Добавить навигацию по сообщениям

## Технологии
- ratatui (tui-rs) - для UI компонентов
- crossterm - для терминальных операций
