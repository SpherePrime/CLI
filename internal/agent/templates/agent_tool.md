Launch a new agent that has access to the following tools: glob, grep, ls, view. When you are searching for a keyword or file and are not confident that you can find the right match on the first try, use the agent tool to perform the search for you.

Pass "agent" to choose which configured agent runs the task. Each agent has
its own model, so pick the one whose model suits the work. Omit "agent" to use
the default search agent.
