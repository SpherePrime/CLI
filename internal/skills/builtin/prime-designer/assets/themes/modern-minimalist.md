# Modern Minimalist

A clean and contemporary theme with a sophisticated grayscale palette for maximum versatility.

## Color Palette

- **Charcoal**: `#36454f` - Primary dark color
- **Slate Gray**: `#708090` - Medium gray for accents
- **Light Gray**: `#d3d3d3` - Backgrounds and dividers
- **White**: `#ffffff` - Text and clean backgrounds

## Typography

- **Headers**: DejaVu Sans Bold
- **Body Text**: DejaVu Sans

## Best Used For

Tech presentations, architecture portfolios, design showcases, modern business proposals, data visualization.

## Verified contrast pairs

Measured with `scripts/contrast.mjs` (WCAG 2.2). Use only these pairs for text and controls.

**Body text (≥ 4.5:1)**

- Charcoal `#36454f` + White `#ffffff` — 9.90:1
- Charcoal `#36454f` + Light Gray `#d3d3d3` — 6.61:1

**Large text ≥ 24px, icons, borders, focus rings (3–4.5:1)**

- Slate Gray `#708090` + White `#ffffff` — 4.05:1

**Decoration only (fails 3:1 with every other swatch)**

- None.

Pairs not listed fail WCAG for text. Derive tints and shades in OKLCH and re-run the checker before adding new pairs.
