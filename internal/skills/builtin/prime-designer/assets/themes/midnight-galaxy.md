# Midnight Galaxy

A dramatic and cosmic theme with deep purples and mystical tones for impactful presentations.

## Color Palette

- **Deep Purple**: `#2b1e3e` - Rich dark base
- **Cosmic Blue**: `#4a4e8f` - Mystical mid-tone
- **Lavender**: `#a490c2` - Soft accent color
- **Silver**: `#e6e6fa` - Light highlights and text

## Typography

- **Headers**: FreeSans Bold
- **Body Text**: FreeSans

## Best Used For

Entertainment industry, gaming presentations, nightlife venues, luxury brands, creative agencies.

## Verified contrast pairs

Measured with `scripts/contrast.mjs` (WCAG 2.2). Use only these pairs for text and controls.

**Body text (≥ 4.5:1)**

- Deep Purple `#2b1e3e` + Silver `#e6e6fa` — 12.57:1
- Cosmic Blue `#4a4e8f` + Silver `#e6e6fa` — 6.14:1
- Deep Purple `#2b1e3e` + Lavender `#a490c2` — 5.41:1

**Large text ≥ 24px, icons, borders, focus rings (3–4.5:1)**

- None.

**Decoration only (fails 3:1 with every other swatch)**

- None.

Pairs not listed fail WCAG for text. Derive tints and shades in OKLCH and re-run the checker before adding new pairs.
