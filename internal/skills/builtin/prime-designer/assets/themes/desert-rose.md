# Desert Rose

A soft and sophisticated theme with dusty, muted tones perfect for elegant presentations.

## Color Palette

- **Dusty Rose**: `#d4a5a5` - Soft primary color
- **Clay**: `#b87d6d` - Earthy accent
- **Sand**: `#e8d5c4` - Warm neutral backgrounds
- **Deep Burgundy**: `#5d2e46` - Rich dark contrast

## Typography

- **Headers**: FreeSans Bold
- **Body Text**: FreeSans

## Best Used For

Fashion presentations, beauty brands, wedding planning, interior design, boutique businesses.

## Verified contrast pairs

Measured with `scripts/contrast.mjs` (WCAG 2.2). Use only these pairs for text and controls.

**Body text (≥ 4.5:1)**

- Sand `#e8d5c4` + Deep Burgundy `#5d2e46` — 7.58:1
- Dusty Rose `#d4a5a5` + Deep Burgundy `#5d2e46` — 5.00:1

**Large text ≥ 24px, icons, borders, focus rings (3–4.5:1)**

- Clay `#b87d6d` + Deep Burgundy `#5d2e46` — 3.18:1

**Decoration only (fails 3:1 with every other swatch)**

- None.

Pairs not listed fail WCAG for text. Derive tints and shades in OKLCH and re-run the checker before adding new pairs.
