# Авторские 3D-сайты

## APEX — машина и её устройство

Детализированный BMW M4 Competition с плавной разборкой на 15 модулей и сохранённым салоном. Ниже — рядный шестицилиндровый двигатель, колесо и новая стойка MacPherson, каждый со своей разборкой. Локальный проект в папке apex.

Подробности: [`apex/README.md`](./apex/README.md).

```powershell
cd apex
npm install
npm run dev
```

Адрес по умолчанию: http://127.0.0.1:5177/.

## PAPERCRAFT — студия бумажных форм

Новая яркая тема: оригами-журавль, раскрывающийся цветок и складчатая гармошка. Матовая 3D-бумага, анимация шарниров, выбор цвета, ручное раскрытие и управление камерой. Отдельный локальный проект.

Подробности: [`papercraft/README.md`](./papercraft/README.md).

```powershell
cd papercraft
npm install
npm run dev
```

Адрес по умолчанию: http://127.0.0.1:5176/.

## AFTERHOURS — музыкальная комната

Новая ночная концепция: медный виниловый проигрыватель, кассета и пульсирующие колонки. Рабочий синтезатор музыки, три настроения, регулировка громкости и атмосферы, механические анимации. Только локально.

Подробности: [`afterhours/README.md`](./afterhours/README.md).

```powershell
cd afterhours
npm install
npm run dev
```

Адрес по умолчанию: http://127.0.0.1:5175/.

## MORPH — новая кинетическая галерея

Светлая экспериментальная галерея с хромированной лентой Мёбиуса, острыми кристаллами и вращающейся архитектурой. Интерактивная лаборатория: вращение, масштаб, выбор материала и разборка объектов. Только локальный проект, без публикации.

Подробности: [`morph/README.md`](./morph/README.md).

```powershell
cd morph
npm install
npm run dev
```

Локальный адрес по умолчанию: http://127.0.0.1:5174/.

## ORBITAL — первая космическая концепция

Проект находится в папке [`orbital`](./orbital). Подробное описание концепции, разработки, 3D-графики, анимаций, технологий и настройки — в [`orbital/README.md`](./orbital/README.md). Работа над его публикацией прекращена по просьбе пользователя.

Запуск:

```powershell
cd orbital
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Для сборки: `npm run build`. Для просмотра сборки: `npm run preview`.
