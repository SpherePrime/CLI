# ORBITAL — За пределами привычного

Авторский сайт о воображаемой космической экспедиции. Задача: самостоятельно придумать тему и визуальный язык, сделать выразительную 3D-графику и живые анимации, а затем объяснить устройство проекта.

## Идея и визуальный язык

Я выбрал космос, потому что эта тема позволяет использовать настоящий объём как главный элемент интерфейса: планету можно вращать, освещение подчёркивает её форму, а кольца и спутник показывают глубину пространства.

Название **ORBITAL** связывает навигацию и содержание: посетитель выбирает свою орбиту и исследует три вымышленных мира.

- **Aurelia** — песочно-золотой мир света и бесконечного рассвета.
- **Nereia** — бирюзовый океанический мир глубины.
- **Obsidian** — тёмный вулканический мир с огненными акцентами.

Палитра построена на почти чёрном фоне, тёплом светлом тексте и оранжевом акценте. Большие заголовки задают масштаб; тонкие линии, координаты и небольшие подписи напоминают приборы экспедиции. Manrope используется для интерфейса, Prata — для выразительных акцентных слов. Шрифты загружаются из Google Fonts; при отсутствии сети работают системные замены.

## Что создано

1. **Главный экран:** WebGL-планета, кольца, спутник, звёздное поле, параллакс от курсора, плавное появление заголовка и элементов.
2. **Выбор мира:** три карточки и переключатели на главном экране. Изменяются выбранная карточка, название, координаты, описание и цвета планеты.
3. **Режим экспедиции:** отдельное модальное пространство с интерактивной планетой, вращением мышью/касанием, масштабированием колесом, характеристиками и переключением миров.
4. **Раздел об опыте:** объёмные орбитальные линии на CSS, объяснение управления и анимированное появление содержимого.
5. **Раздел миссии:** финальный смысловой блок с кнопкой входа в экспедицию.
6. **Атмосферный звук:** включаемый пользователем синтезированный фон.
7. **Адаптация:** мобильная навигация, вертикальные карточки, другая позиция и масштаб планеты на узком экране.
8. **Оформление:** собственный SVG-фавикон, метаданные страницы, бегущая строка, зерно и индикатор прокрутки.

Все миры, координаты и характеристики вымышлены. Это художественная интерактивная выставка, а не научная модель или сервис продажи космических путешествий.

## Технологии и зачем они нужны

| Технология | Роль | Почему выбрана |
| --- | --- | --- |
| JavaScript ES Modules | Поведение страницы и управление сценами | Для одной страницы достаточно прозрачной структуры без дополнительного UI-фреймворка |

| OrbitControls | Вращение и масштабирование в экспедиции | Готовое управление камерой мышью и касанием с плавным затуханием движения |
| GSAP | Вступление, переходы цветов, вращение при смене мира | Удобно синхронизировать несколько свойств и настроить темп анимации |
| ScrollTrigger | Появление секций и прогресс страницы | Связывает движение интерфейса с реальной прокруткой |
| CSS Grid / Flexbox | Адаптивная композиция | Позволяет сохранять иерархию страницы на больших и маленьких экранах |
| CSS transforms / perspective | Объёмные орбиты в разделе опыта | Для лёгких геометрических элементов отдельный WebGL-рендерер не нужен |
| Web Audio API | Атмосферный звук | Синтезирует фон локально, без аудиофайлов и стороннего проигрывателя |
| HTML dialog | Модальная экспедиция | Нативный модальный слой, фокус внутри окна и закрытие Escape |
| Sites | Приватное размещение статической сборки | Позволяет передать сайт как открываемый результат, сохранив исходники локально |

Версии и точные разрешённые зависимости зафиксированы в `package-lock.json`. Весь Three.js и GSAP включаются в сборку; во время просмотра их не нужно получать с CDN.

## Как устроена 3D-сцена

### Планета

`createPlanet()` создаёт группу Three.js. В ней находятся сфера, атмосферная оболочка, кольца и маленький спутник. Основная сфера — `SphereGeometry` радиусом 1.7 с 96 горизонтальными и 64 вертикальными сегментами.

Поверхность формируется в фрагментном шейдере. Функции `hash`, `noise` и `fbm` создают многослойный псевдослучайный рисунок. Он смешивается с полосами и мелкими деталями. Три цветовых параметра — `uLight`, `uMid`, `uDark` — определяют палитру. `uSeed` меняет рисунок для каждого мира.

Шейдер вычисляет направленное освещение по нормали поверхности. Затемнение и подсветка края делают форму читаемой. Это художественное освещение: материал не претендует на физически точную симуляцию атмосферы.

### Атмосфера

Чуть более крупная сфера окружает планету. Прозрачный шейдер усиливает подсветку у края; аддитивное смешивание создаёт лёгкое сияние, не закрывающее поверхность.

### Кольца

Основное кольцо — `RingGeometry` с собственным шейдером и радиальной разметкой UV. Дополнительные окружности построены из линий. Вся группа наклонена, поэтому часть колец проходит перед планетой, а часть скрывается за ней.

### Звёзды

1300 точек хранятся в `BufferGeometry`. У каждой есть положение и цвет. `PointsMaterial` рисует их одним набором геометрии, что дешевле большого количества отдельных объектов.

### Две интерактивные сцены

Главная сцена управляется мягким параллаксом: положение указателя постепенно влияет на углы группы. Планета медленно вращается вокруг своей оси.

Экспедиция использует отдельный рендерер и `OrbitControls`. В ней можно свободнее исследовать форму и менять расстояние до планеты. При открытии создаётся сцена, а при следующих открытиях она используется повторно.

### Карточки миров

Превью карточек создаются из тех же 3D-материалов в небольшом вспомогательном рендерере. Его изображение сохраняется в `data:` URL и показывается как обычная картинка. После этого вспомогательные материалы, геометрия и WebGL-контекст освобождаются.

Это сознательный компромисс: карточки показывают реальные рендеры сцены, но не запускают три дополнительных постоянных цикла рендеринга.

## Как работают анимации

- **Вступление:** GSAP поднимает элементы из небольшого смещения и проявляет их с последовательной задержкой.
- **Параллакс:** положение указателя сглаживается, чтобы планета не дёргалась за мышью.
- **Смена мира:** GSAP плавно меняет компоненты цветов и seed материала, одновременно поворачивая поверхность.
- **Прокрутка:** ScrollTrigger проявляет секции при входе в экран и управляет верхней полосой прогресса.
- **Орбиты:** CSS `perspective`, `rotateX`, `rotateY`, `rotateZ` создают пространственную геометрию и непрерывное движение в разделе опыта.
- **Вход в экспедицию:** камера плавно приближается к планете, создавая ощущение перехода в её пространство.
- **Микроанимации:** карточки поднимаются и наклоняются вслед за мышью, кнопки откликаются движением и светом, индикатор прокрутки показывает направление. На сенсорном экране наклон отключён.
- **Звук:** четыре синусоидальных осциллятора формируют спокойный фон. Усиление меняется постепенно, без резкого щелчка.

Звук изначально выключен и создаётся только после нажатия пользователя. При уходе со вкладки он приглушается.

## Производительность и доступность

- Pixel ratio ограничен 1.8 для основных сцен и 1.5 для рендера превью.
- Главная сцена не перерисовывается, когда находится вне области просмотра.
- Скрытая вкладка не рендерит сцены; закрытая экспедиция тоже не рендерится.
- `ResizeObserver` подстраивает размеры рендера и перспективу камеры.
- `prefers-reduced-motion` отключает декоративные движения и автоповорот камеры.
- Кнопки имеют подписи, состояния `aria-pressed` и видимый фокус.
- Выбор мира объявляется через `aria-live`.
- Ссылки ведут к реальным разделам страницы; все основные кнопки открывают экспедицию.
- Если WebGL недоступен, остаются текст, выбор миров и упрощённая иллюстрация. Вращение 3D в таком режиме отсутствует.

Основной JavaScript включает 3D-движок, поэтому он тяжелее скрипта обычного текстового лендинга. Качество и плавность зависят от графического процессора и настроек браузера. Продвинутые эффекты постобработки намеренно не подключались: свет и материал создают выразительность без дополнительного GPU-прохода.

## Запуск

Требуется Node.js, совместимый с Vite 7: 20.19+ или 22.12+.

Из корня рабочей папки:

```powershell
cd orbital
npm install
npm run dev
```

Откройте локальный адрес из вывода Vite. Если порт занят, Vite покажет другой свободный порт.

Для воспроизводимой установки на другой машине с имеющимся lock-файлом используйте `npm ci`.

```powershell
npm run build
npm run preview
```

Не открывайте `index.html` двойным щелчком: ES Modules и зависимости рассчитаны на HTTP-сервер Vite либо готовую сборку.

## Что и где менять

| Что хочется поменять | Где |
| --- | --- |
| Названия, палитры и характеристики миров | Массив `worlds` в `src/main.js` |
| Главный заголовок и содержание разделов | `index.html` |
| Основной оранжевый цвет | Переменная `--orange` в `src/style.css` |
| Размеры, отступы, типографика | Правила `.hero`, `.section`, `.header` и медиазапросы |
| Рисунок поверхности | `fragmentShader`, функции `noise` и `fbm` |
| Кольца, спутник и атмосфера | `createPlanet()` |
| Скорость вращения | Цикл `animate()` и `controls.autoRotateSpeed` |
| Длительность смены мира | `transitionPlanet()` |
| Вступление и появление секций | Блок `gsap.matchMedia()` в конце `src/main.js` |
| Звуковые частоты и громкость | Обработчик `.sound-control` |
| Значок вкладки | `public/favicon.svg` |

После изменения текстов в массиве миров проверьте также статические подписи карточек в HTML. Для публикации обновлений сначала пересоберите сайт.

## Проверка

Production-сборка проверяется командой `npm run build`. Дополнительно проверяются реальные пользовательские сценарии в браузере: выбор мира, открытие экспедиции, переход к следующему миру, закрытие окна, мобильная компоновка и отсутствие ошибок JavaScript.

Сайт не содержит backend, авторизации, платёжных операций, аналитики или форм сбора данных. Звук создаётся локально. Планеты не требуют внешних изображений или моделей; единственная внешняя визуальная зависимость — Google Fonts.
