# ORBITAL

An original Russian-language space expedition exhibition. A warm orange and near-black art direction, oversized typography, true WebGL planets, orbit rings and star particles form a cinematic interactive page.

## Implementation
1. Build a Vite single-page application using Three.js and GSAP; no backend or external service claims.
2. Present the hero with a rotating shader planet, pointer parallax, orbit rings and a working expedition button. Open the local preview once this coherent scene works.
3. Add three selectable fictional worlds, planet transitions, journey sections, sound opt-in, a cinematic exploration overlay and responsive navigation.
4. Respect reduced motion, pause work while hidden, cap rendering resolution and preserve content if WebGL is unavailable.
5. Verify production build, desktop/mobile rendering, world selection and controls. Publish the completed static output privately through Sites if available.

## Verification
Use browser interaction tests for the actual visual and navigational journeys instead of unit tests mirroring decorative markup. Check for runtime errors, clipping, keyboard access and reduced-motion behavior.
