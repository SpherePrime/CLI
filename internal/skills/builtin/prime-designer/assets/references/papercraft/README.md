# PAPERCRAFT — Один лист. Тысяча возможностей.

Авторский интерактивный сайт о бумаге и оригами. Создан как отдельный проект в папке `papercraft`. Запускается только локально; публикация и подключение хостинга не выполнялись.

## Идея и визуальный язык

После космоса, кинетической галереи и музыкальной комнаты я выбрал новую тему: небольшую экспериментальную студию бумажных форм. Здесь главный эффект — превращение плоскости в объём через движение складок.

Кобальтовый фон создаёт насыщенную сцену, лимонный цвет выделяет заголовки и действия, розовая и мятная бумага добавляет тёплую, почти игрушечную атмосферу. Крупная типографика, технические подписи, тонкие рамки и наклонённая наклейка связывают художественную часть с интерфейсом мастерской.

Все основные объекты — настоящие 3D-модели, созданные программно. Готовые модели, фотографии объектов и видео вместо 3D не использовались.

## Запуск

Нужен Node.js, совместимый с Vite 7: 20.19+ или 22.12+.

```powershell
cd papercraft
npm install
npm run dev
```

Открыть **http://127.0.0.1:5176/**. Сервер привязан к `127.0.0.1`. Если порт занят, Vite покажет другой адрес в терминале.

```powershell
npm run build
npm run preview
```

Первая команда создаёт сборку в `dist`, вторая показывает её локально на порту 4176. Ни одна из этих команд не публикует сайт.

## Что можно делать

- Переключать журавля, цветок и гармошку на первом экране или в мастерской.
- Выбирать розовую, лимонную, мятную или светлую бумагу. Цвет меняется сразу в обеих сценах.
- Менять степень раскрытия ползунком. Двигаются сами поверхности, а не только камера.
- Останавливать и возобновлять движение; кнопки в разных разделах синхронизированы.
- Вращать модель перетаскиванием и приближать колесом в мастерской. На телефоне доступны жесты OrbitControls.
- Сбрасывать ракурс камеры отдельной кнопкой.
- Переходить между разделами, пользоваться мобильным меню.

## Технологии и зачем они нужны

| Инструмент | Применение |
| --- | --- |
| Three.js | Геометрия бумаги, перспективная камера, освещение, материалы, тени и WebGL-рендеринг в реальном времени. |
| BufferGeometry | Собственные треугольные грани журавля и лепестков: точный контроль вершин и выраженные линии сгиба. |
| Group | Иерархия шарниров. Каждая складка вращается относительно своего края. |
| MeshStandardMaterial | Матовая бумага: высокая шероховатость, отсутствие металлического блеска, видимые обе стороны листа. |
| OrbitControls | Поворот и масштаб камеры с плавным затуханием в интерактивной мастерской. |
| GSAP | Входная хореография, плавные переходы моделей и раскрытия, последовательное появление текста. |
| ScrollTrigger | Появление блоков при прокрутке, индикатор прогресса и поворот декоративного знака. |
| Vite | Локальная разработка, обновление страницы при изменениях, сборка модулей. |
| HTML и CSS | Семантические разделы, адаптивная композиция, кнопки, меню, фокус клавиатуры и визуальная система. |
| IntersectionObserver | Отложенное создание второй 3D-сцены и прекращение её отрисовки вне экрана. |
| ResizeObserver | Пересчёт размеров canvas, камеры и положения объекта при изменении ширины. |

React здесь не требовался: состояние компактное, а основной интерфейс состоит из нескольких непосредственных управляющих элементов. Использован обычный JavaScript с ES-модулями.

Шрифты **Golos Text** и **IBM Plex Mono** подключены через Google Fonts: первый хорошо работает с крупной кириллицей, второй подчёркивает технические подписи. Для них есть системные fallback-шрифты; загрузка веб-шрифтов требует сети. 3D-модели не загружаются с внешних серверов.

## Как создавались объекты

### Журавль

Корпус, шея, клюв и хвост собраны из треугольных граней. Крылья находятся в отдельных группах с точками вращения у корпуса. Ползунок меняет угол крыльев; синусоидальное движение добавляет мягкий взмах. На поверхностях есть тонкие линии сгиба и небольшие различия оттенков.

### Цветок

Девять ромбовидных лепестков распределены вокруг центра. Каждый имеет собственный шарнир; угол открытия зависит от ползунка. При включённом движении лепестки получают небольшую фазовую задержку, поэтому цветок дышит последовательно, а не двигается одним жёстким блоком. Стебель имеет шесть граней, листья — простые бумажные треугольники.

### Гармошка

Шестнадцать прямоугольных панелей связаны цепочкой вложенных групп. Каждый следующий шарнир расположен на краю предыдущей панели. Чередующиеся углы создают складчатую поверхность, сохраняя соединение её частей. Изменение угла одновременно меняет длину и объём гармошки. Небольшое движение складок создаёт ритмическую волну.

Это художественные модели с управляемой кинематикой. Здесь нет симуляции физики бумаги, столкновений или точного воспроизведения реальных инструкций оригами. Диапазон ползунка означает визуальное раскрытие конкретной формы: 100% не превращает журавля обратно в исходный квадрат.

## Анимации и свет

Первый объект появляется с подъёмом и разворотом. Заголовок, описание и кнопки входят последовательно. Движение указателя мягко меняет перспективу главной сцены. При смене формы новая модель разворачивается в рабочее положение.

Для бумаги использовано полусферическое освещение, тёплый направленный ключевой свет и холодный контровой свет. Тени на прозрачной плоскости визуально связывают объект с фоном. ACES tone mapping удерживает яркие цвета в приятном диапазоне. Шероховатость материала 0.9 и metalness 0 сохраняют матовую поверхность.

Три иллюстрации в разделе «Всё начинается с одного сгиба» генерируются из той же 3D-гармошки при разных углах. Они один раз рендерятся в WebP непосредственно в браузере; временный renderer после этого освобождается. Это сохраняет визуальную согласованность без трёх дополнительных постоянно работающих сцен.

## Производительность и доступность

- Плотность пикселей ограничена значением 1.6, чтобы уменьшить нагрузку на графический процессор.
- Для теней используется карта 1024 × 1024; геометрия намеренно малополигональная.
- Мастерская создаётся при приближении к её разделу.
- Сцены не рисуются за пределами области видимости и при скрытой вкладке.
- Старые геометрии и материалы освобождаются при переключении модели.
- `prefers-reduced-motion` отключает автоматическое движение, параллакс и входные анимации. Переключение форм и ручное раскрытие остаются доступными.
- Кнопки имеют состояния `aria-pressed`, меню — `aria-expanded`, ползунок — подпись; фокус клавиатуры виден.
- При отсутствии WebGL остаются текст, навигация и графическая заглушка с сообщением.
- Для телефона перестроены сетки, положение модели, размеры текста и меню. Мастерская занимает отдельный полноценный блок.

Three.js составляет основную часть JavaScript-сборки. Vite может предупредить о чанке более 500 kB: это предупреждение о размере, а не ошибка сборки. Разделение движка на дополнительные чанки имеет смысл при дальнейшем развитии проекта и анализе реальной загрузки.

```text
  README.md              — это описание
```

## Как менять проект

Цвета моделей находятся в `palette` в `src/paper.js`, а цвета интерфейса — в CSS. Формы создаются в `createPaper`, поведение шарниров задаётся в `posePaper`. Камера, освещение и адаптивный масштаб находятся в `PaperScene.resize` и конструкторе сцены. Тексты страницы редактируются в `index.html`.

Для добавления четвёртой формы потребуется дополнить `forms`, геометрию и позу в `paper.js`, а также кнопку в HTML. Все сцены используют общее состояние, поэтому нужно сохранить этот принцип и синхронизировать новые контролы через `main.js`.

Проект представляет собой интерактивную художественную страницу. Серверная часть, учётные записи, отправка форм, аналитика и сохранение пользовательских настроек не подключены.
