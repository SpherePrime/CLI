# PAPERCRAFT

Локальная интерактивная студия бумажных механизмов. Кобальтовый фон, лимонные акценты, розовая бумага и белая типографика. Три новых настоящих 3D-объекта: складчатый журавль с шарнирными крыльями, цветок с раскрывающимися лепестками, гармошка из чередующихся граней. GSAP управляет последовательными сгибами и переходами; Three.js — матовой бумажной геометрией, светом и тенями. Пользователь выбирает объект, цвет, движение, управляет степенью раскрытия и запускает сцену. Нет хостинга или публикации. README объясняет концепцию, геометрию, анимации, доступность и запуск.
