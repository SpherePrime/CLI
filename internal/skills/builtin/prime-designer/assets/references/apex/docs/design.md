# APEX — BMW M4

Главная машина заменена детализированным BMW M4 Competition M Package, автор SRT Performance, CC BY 4.0. Кузов и интерьер сохраняют координаты оригинальной модели, части разделены на пятнадцать групп для обратимой разборки. GLB хранится локально; исходник сохранён отдельно.

Подвеска переделана в цельную программную иллюстрацию MacPherson. Отдельный двигатель — рядная шестёрка с двумя турбинами. Самостоятельное колесо иллюстрирует послойное устройство диска и тормозов.

Графит, тёплый белый, оранжевые элементы интерфейса и синяя краска BMW. Three.js, GLTFLoader, Meshopt, OrbitControls, GSAP. Подготовка модели: glTF Transform и Sharp. Публикация не выполняется. Расширенные проверки пропущены по просьбе пользователя.
