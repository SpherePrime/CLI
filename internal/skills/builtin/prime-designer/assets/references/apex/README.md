# APEX — BMW M4 Competition

Локальный интерактивный сайт с детализированным BMW M4 и обратимой разборкой. Проект находится в папке `apex`, адрес — http://127.0.0.1:5177/. Публикация не выполнялась.

## Что переделано

Первоначальный программный кузов заменён подготовленной моделью **BMW M4 Competition M Package**. У прежнего объекта контуры дверей и кузова рассчитывались независимо, а часть интерьера пересекалась с оболочкой. Теперь внешние панели и салон используют исходные координаты одной модели.

У BMW сохранены решётки, фары, кузов, окна, зеркала, колёса, элементы M Performance, сиденья, руль, приборная панель, центральная консоль, дверные карты и текстуры. Для разборки геометрия организована в 15 групп. Сборка не заменяется упрощёнными деталями: те же полигоны возвращаются в исходные положения.

Стёкла используют отдельные прозрачные материалы и не отбрасывают непрозрачную тень на интерьер. У непрозрачного салона включена запись глубины и двустороннее отображение поверхностей, поэтому внутренние детали сохраняют видимость при разборке и смене ракурса.

Прежняя условная подвеска полностью заменена на модель стойки **MacPherson** с литым нижним рычагом, сайлентблоками, поворотным кулаком, ступицей, корпусом амортизатора, хромированным штоком, спиральной пружиной, верхней опорой, тарелками, рулевой тягой и тягой стабилизатора. Отдельная демонстрация двигателя заменена на рядную шестёрку с двумя турбинами.

## Запуск

Нужен Node.js, совместимый с Vite 7: 20.19+ или 22.12+.

```powershell
cd apex
npm install
npm run dev
```

Открыть **http://127.0.0.1:5177/**. Vite слушает `127.0.0.1`; если порт занят, терминал покажет следующий свободный адрес.

```powershell
npm run build
npm run preview
```

Сборка создаётся в `dist`, её локальный просмотр работает на порту 4177. Это не команды публикации.

## Управление

- «Разобрать машину» плавно разводит модули BMW; «Собрать машину» возвращает их обратно.
- Каждая кнопка двигателя, колеса и подвески управляет своей сценой.
- Повторное нажатие во время движения плавно разворачивает анимацию.
- Перетаскивание вращает камеру, колесо мыши меняет масштаб.
- Кнопка ↻ включает и выключает автоматический обзор машины.
- Кнопка ⌖ сбрасывает ракурс, сохраняя состояние разборки.

Пока локальный GLB загружается и декодируется, кнопка машины показывает загрузку и недоступна. После загрузки она включается автоматически.

## Как подготовлена машина

Скрипт `scripts/prepare-bmw.mjs` выполняет последовательную обработку:

1. Читает исходный GLB и его мировые трансформации.
2. Приводит модель к общей системе координат: X — длина, Y — высота, Z — ширина. Длина в сцене составляет 6.3 условной единицы.
3. Находит связанные компоненты геометрии. При анализе совпадающие координаты объединяются только для определения связности; UV-развёртки и исходные вершины сохраняются в экспортируемых данных.
4. Относит цельные компоненты к кузову, капоту, дверям, стёклам, салону, механике и четырём колёсам по материалу и пространственному расположению.
5. Собирает компоненты с одинаковым материалом внутри каждого модуля, уменьшая число отдельных вызовов рисования.
6. Ограничивает текстуры размером 1024 px и преобразует их в WebP.
7. Применяет Meshopt-сжатие и экспортирует `public/models/bmw-m4.glb`.

Геометрическое упрощение не применяется. Подготовленный файл занимает примерно **7.8 MB** вместо исходных **22.7 MB**. В нём 15 модулей и 87 групп отрисовки по материалам. Атрибуция сохраняется в метаданных.

Повторить подготовку:

```powershell
npm run prepare:bmw
```

Исходный файл находится вне `public`, поэтому он не копируется в веб-сборку. Готовый GLB хранится локально; при просмотре сайт не обращается к Sketchfab или GitHub за машиной.

Сведения о разделении сохранены в `docs/bmw-assembly.json`, а инвентаризация компонентов — в `docs/bmw-components.json`.

## Новая подвеска

Геометрия находится в `src/suspension.js`. Детали создаются вокруг общих посадочных координат. Корпус амортизатора, шток, пружина, тарелки и верхняя опора используют одну наклонную ось. Нижний рычаг соединён с поворотным кулаком через шарнир; кулак содержит ступицу и пять креплений колеса.

Рычаг выполнен через `ExtrudeGeometry`: это объёмная деталь с внутренним вырезом и скруглёнными краями. Пружина строится по пространственной спирали с 256 сегментами. Шток имеет металлическую поверхность, втулки — матовую резину, корпус — тёмный металл, пружина — синий цвет. Крепёж моделируется отдельными цилиндрами и шестигранниками.

При разборке отдельно расходятся девять модулей: рычаг, кулак, корпус, шток, пружина, верхняя тарелка с подшипником, опора, рулевая тяга и тяга стабилизатора.

Это авторская иллюстрация архитектуры MacPherson, а не точная заводская CAD-копия подвески BMW.

## Полностью новый двигатель

Предыдущий двигатель заново смоделирован в `src/inline-six.js`. Основной ориентир — архитектура BMW S58: рядная шестёрка, два распредвала, четыре клапана на цилиндр, два выпускных коллектора по три цилиндра и две турбины. Это авторская программная визуализация, не заводская CAD-модель и не точная копия всех каналов и креплений S58. BMW и его моторный отсек из исходного GLB при этой переделке не изменялись.

Для устройства двигателя использован технический материал BMW **S58 Engine / Technical Training, 2019**: [официальный адрес руководства](https://bmwtechinfo.bmwgroup.com/tech_training_manual/ST1926%20S58%20Engine.pdf), [доступная копия для просмотра](https://www.billswebspace.com/ST1926%20S58%20Engine.pdf). Сам PDF, его картинки и заводская геометрия в сайт не включены.

### Как создавалась геометрия и зачем

- **Блок и головка.** `Shape`, `Path` и `ExtrudeGeometry` формируют сложные контуры, фаски и шесть настоящих отверстий цилиндров. Это отверстия в геометрии, а не нарисованные тёмные круги. Внутри стоят открытые гильзы. Нижний картер имеет закруглённый профиль, полость, рёбра, крепёжные приливы и пробки каналов.
- **Поддон.** Собственная сетка соединяет поперечные сечения разной ширины. Благодаря этому стенки сужаются книзу. Есть фланец, нижние рёбра и сливная пробка.
- **Поршни и коленвал.** Созданы шесть поршней с кольцами, пальцами, двутавровыми шатунами и открытыми нижними головками. Положения поршней и наклоны шатунов привязаны к фазам шатунных шеек. На валу есть коренные участки, щёки и противовесы; маховик с зубчатым венцом снимается отдельно.
- **Газораспределение.** Отдельный модуль содержит два распредвала, 24 клапана и их пружины. Он находится внутри головки под крышкой при сборке и раскрывается в разнесённом виде.
- **Крышка.** Фигурная оболочка, прокладка, рёбра, крепёж, маслозаливная крышка и патрубок вентиляции. Надпись M POWER и цветные полосы создаются через CanvasTexture непосредственно в браузере, без загрузки внешних картинок.
- **Впуск и охлаждение наддува.** Шесть изогнутых каналов, общий ресивер, дроссельный фланец и отдельный охладитель с рёбрами и штуцерами. Изгибы создаются по пространственным кривым через TubeGeometry.
- **Выпуск и турбины.** Шесть труб сходятся в два коллектора. Корпус каждой турбины построен как объёмная спираль с растущим сечением через BufferGeometry. Открытый впуск показывает лопатки компрессора. Добавлены горячая часть, актуатор wastegate, тяга, трубка и выпускной патрубок.
- **Теплозащитный экран.** Отдельная изогнутая сетка огибает выпуск и имеет мелкую гофрировку. Он снимается до разборки коллекторов.
- **Навесное оборудование.** Передняя крышка, ремень и шкивы, генератор с вентиляционными окнами и медной внутренней частью, масляный фильтр с охладителем, топливная рампа, форсунки и проводка.

### Материалы, свет и анимация

Раздельные материалы используются для литого алюминия, обработанного металла, стали, горячего чугуна, резины, пластика и латунных трубок. Микрорельеф литья создаёт детерминированная процедурная DataTexture в bumpMap. Он добавляет шероховатость поверхности без множества дополнительных полигонов. Экспозиция и свет двигателя настроены отдельно, чтобы обработанные кромки читались на более тёмной отливке.

Двигатель имеет **18 независимо движущихся узлов**. Сначала расходятся крышка, экран и внешнее оборудование, затем головка, газораспределение и поршни, в конце — коленвал и поддон. Крышка, экран, впуск и маховик также немного поворачиваются. GSAP плавно меняет параметр разборки за **3.1 секунды**; повторное нажатие разворачивает движение с текущего положения. Камера расширяет обзор и сдвигает центр композиции.

Все детали возвращаются к сохранённым исходным координатам. Неподвижные поверхности внутри каждого узла объединяются по материалу с помощью `mergeGeometries`: это уменьшает число вызовов отрисовки, сохраняя детализацию и независимую анимацию узлов. Двигатель создаётся локально в браузере; дополнительные модели, сервисы и загрузки для него не нужны.

## Отдельное колесо

Отдельное колесо остаётся программной моделью с шиной, пятью спицами, тормозным ротором, суппортом и ступицей. На BMW стоят её исходные модельные колёса. Поэтому отдельный узел иллюстрирует конструкцию колеса, не выдаваясь за точный штатный диск BMW.

## Анимация

У каждой сцены собственный параметр разборки от 0 до 1. GSAP изменяет его за 2.6 секунды (для нового двигателя — за 3.1 секунды) с `power3.inOut`. Для деталей заданы исходная позиция, вектор движения и дополнительный угол. Небольшие задержки создают последовательную хореографию.

Повторное нажатие перенаправляет текущий tween, сохраняя промежуточные координаты. Камера расширяет поле обзора и поднимает точку наблюдения по мере разборки, чтобы верхние детали помещались в кадре.

## Свет, доступность и нагрузка

BMW показан на светлом фоне, отдельные механизмы — на графитовом. Использованы полусферическое освещение, тёплый ключевой и холодный контровой свет, процедурные отражения, ACES tone mapping и прозрачная плоскость теней.

Плотность пикселей ограничена 1.5. Дополнительные сцены создаются при приближении к ним. Невидимые сцены и скрытая вкладка не отрисовываются. Карта основной тени — 2048 × 2048, дополнительных — 1024 × 1024.

У кнопок есть `aria-pressed`, у меню — `aria-expanded`, фокус клавиатуры виден. `prefers-reduced-motion` отключает автоматические движения и делает разборку мгновенной. Мобильный интерфейс перестраивается в одну колонку.

Расширенные тесты не запускались по прежней просьбе пользователя. Модель и механизмы являются интерактивной визуализацией, не инструкцией по ремонту. Серверной части, регистрации, отправки данных и хостинга нет.
