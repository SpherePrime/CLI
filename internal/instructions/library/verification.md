# Verifying completion

Support completion with fresh observed evidence.
Derive checks from intended behavior; run relevant tests, builds or direct invocation. Observe output and exit status and exercise changed branches plus meaningful regression cases. Validate CLI flags at their command boundary, routes with status/headers/body and libraries through a minimal consumer import. Use isolated inputs or safe modes for destructive paths. Passing tests do not prove unexercised features. Report failures, skipped checks and environment limits; rerun after corrections. Observe remote deployment before claiming success.
