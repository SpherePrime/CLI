# Choosing data visualizations

Choose the form from the data question before styling.
Use stat tiles for single values, tables for many meaningful classes, bars for magnitudes, lines for trends, diverging bars for baseline differences and stacked bars for shares. Highlight relevant series and de-emphasize context. Use ordered color for magnitude and categorical color for identity; group or facet many series instead of generating hues. Preserve truthful baselines, units, missing values and uncertainty. Include sources and accessible alternatives; use supported chart tools.
