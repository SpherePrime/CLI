# Creating Git commits safely

Create focused commits from inspected verified changes.
Inspect branch, status, upstream and all diffs. Preserve concurrent edits and synchronize without discarding work. Stage specific paths, respect ignores and inspect the staged diff. Match message style and explain purpose. Keep the configured user as author, without assistant attribution. Prefer new commits over amendments. On hook failure fix, restage and make a new commit; do not bypass hooks. Push or rewrite history only with existing authorization. Confirm the commit and final status.
