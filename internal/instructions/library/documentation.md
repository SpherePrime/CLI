# Writing documentation and reports

Write reader-focused documentation grounded in actual behavior.
Choose structure for working notes, reference, proposal or report. Lead with the result or decision; keep setup accurate, examples executable and terminology defined. Distinguish measurements, inference and speculation. Add contents only for substantial documents. Preserve existing content and concurrent edits instead of reapplying templates. Use write or edit locally and discovered connectors within authorization. Verify links, headings, placeholders, language and format.
