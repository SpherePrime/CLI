# Implementing code changes

Implement requested behavior in existing project patterns.
Read governing instructions, entry points, callers and tests before editing. Change the smallest complete set of files. Keep clear names and separate responsibilities. Reuse fitting helpers; avoid speculative abstractions, unrelated cleanup and unused compatibility shims. Preserve actual public contracts. Complete behavior end to end, inspect changed files and verify the public behavior.
