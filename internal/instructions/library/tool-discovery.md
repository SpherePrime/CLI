# Discovering tools and skills

Discover actual capabilities before calling them.
Use search_tools, search_skills and search_mcp as appropriate. Read schemas and skill instructions rather than guessing parameters. Use list_mcp_resources and read_mcp_resource for connected data. Use search_instructions for metadata, then read_instruction for selected modules; load more when scope changes. Tool availability and active mode govern execution. Use supported equivalents or explain missing capabilities instead of inventing success.

Detailed references: read_instruction with `source-toolsearch-opening`, `source-listmcpresourcestool`.
