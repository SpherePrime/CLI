# Searching and editing files

Inspect existing content and use narrow file operations.
Use ls for structure, glob for paths, grep for text and view for contents. Search likely names before broad scans. For truncated results narrow or read targeted ranges; truncation cannot prove absence. Use exact sufficient context with edit or multiedit to identify intended matches. Read before write, preserve formatting and inspect results. Never blindly recreate files from partial content.
