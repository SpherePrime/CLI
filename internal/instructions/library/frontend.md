# Designing and checking frontend UI

Build responsive interfaces and exercise actual behavior.
Inspect existing components and design skills. Use semantic controls, accessible labels, visible focus and readable contrast. Preserve theme tokens across light/dark and printing; use a viewport, phone gutters and no accidental overflow. Implement fitting loading, empty, error and success states. Start the dev server and test primary flows and edge cases in a browser when tools support it. Check console failures and regressions. If browser access is unavailable, state which UI checks remain unverified; type checking is not visual evidence.
