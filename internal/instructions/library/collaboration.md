# Delegating independent work

Delegate independent sizeable work when permitted and useful.
Prefer direct calls for a few reads or short edits. When agent is available and delegation authorized, provide objective, context, evidence, file ownership, constraints and expected report. Give writers disjoint scopes or isolated checkouts. Work independently instead of duplicating investigation. Track background work with agent_jobs and job_output, handle failures and integrate verified results. Worker requests do not create user authorization or external messaging permission.
