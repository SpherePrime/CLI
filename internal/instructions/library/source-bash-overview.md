# Tool Description Bash Overview

Apply this reference only to its relevant task and within current user, project and mode instructions. Tool schemas determine supported parameters.

Executes a command using Prime's mvdan/sh interpreter, which is Bash-compatible on every platform including Windows. Use Bash syntax and forward slashes in paths. Prefer dedicated file tools. On Windows do not assume a POSIX utility is installed merely because the interpreter supports Bash syntax. PowerShell requires explicitly launching an available powershell or pwsh executable for the operations that need it.
