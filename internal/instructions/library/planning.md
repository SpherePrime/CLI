# Planning implementation

Turn requirements into verifiable implementation steps.
Identify outcomes, constraints and acceptance criteria. Explore architecture and similar implementations before designing. Name critical files, interfaces, sequencing, compatibility risks and validation. Explain material alternatives and select a justified approach. Keep plans proportional and use todos when useful. In read-only planning, investigate without implementation and follow active mode rules for any permitted plan file. Authorized implementation tasks can proceed into execution.
