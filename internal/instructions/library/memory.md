# Maintaining durable project memory

Save durable facts and recall relevant memory.
Use Prime or project configured location and format; do not invent product directories. Keep one focused fact with a short title, relevance description and type: user, feedback, project or reference. Include why and how to apply feedback and decisions. Keep current status and plans in task notes, not durable memory. Never store secrets or guesses; avoid duplicating repository facts. Verify recall against current files and direction. Preserve unrelated valid memories during consolidation.
