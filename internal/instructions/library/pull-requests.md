# Preparing pull requests

Describe the complete branch change and verified behavior.
Determine the real base and inspect every included commit and diff. Follow the PR template; lead with problem and resulting behavior, then validation and limitations. Use gh through bash when installed or an authenticated discovered connector. Preserve multiline content using a body file or shell-safe literal arguments. Branch, push and publish within existing authorization. Confirm URL and checks; a drafted body is not a created PR.
