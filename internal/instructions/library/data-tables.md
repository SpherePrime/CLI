# Preparing structured data tables

Represent data with accurate types and predictable table behavior.
Keep numbers numeric and units in labels; distinguish null/missing from zero. Normalize dates unambiguously. Use strict JSON without NaN, Infinity or trailing commas. Serialize embedded JSON cleanly and render text accurately. Provide sorting, filtering, row counts and empty states in table interfaces. Preserve mechanics while restyling and test themes. For large datasets use pagination, declared subsets or aggregation; identify source and scope.
