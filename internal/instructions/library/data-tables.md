# Preparing structured data tables

Represent data with accurate types and predictable table behavior.
Keep numbers numeric and units in labels; distinguish null/missing from zero. Normalize dates unambiguously. Use strict JSON without NaN, Infinity or trailing commas. Escape script boundaries in embedded JSON and safely render text. Provide sorting, filtering, row counts and empty states in table interfaces. Preserve mechanics while restyling and test themes. For large datasets use pagination, declared subsets or aggregation; identify source and scope.
